QUESTIONS & ANSWERS
FAQ
How accurate is the drowsiness detection?▾
The custom CNN model achieved 99.14% test accuracy on 12,737 unseen images from the MRL Eye Dataset — only 110 errors total. Across 30 training epochs the model reached 99.10% validation accuracy with a 0.22% train-val gap, indicating strong generalization with no overfitting.
What hardware do I need?▾
Just a standard webcam and a computer running Python. No GPU is required — inference runs on CPU. For in-vehicle use, a Raspberry Pi can host the Flask server with the dashboard on any browser-capable screen.
How is the alert triggered?▾
When the model continuously classifies Sleepy for a configurable threshold (default 2 seconds), an audio beep and full-screen red overlay fire simultaneously. The alert repeats every second until eyes are detected as open again.
Does it work in low light?▾
Performance degrades in very low light since Haar Cascade requires adequate contrast. For night driving, an infrared camera or cabin LED lighting is recommended. Future versions may incorporate IR-compatible models.
Is any data stored or sent to a server?▾
No. All processing happens locally. The Flask server runs on localhost and no video data or personal information leaves your device. Session statistics are stored in memory only and cleared when the server restarts.
Can it be used for fleet management?▾
Yes — the session report API (/summary) can be extended to POST data to a fleet dashboard. Each vehicle running SafeDrive AI could feed anonymised safety ratings and event counts to a central system for fatigue pattern analysis across drivers and shifts.
